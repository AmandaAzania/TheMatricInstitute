THE MATRIC INSTITUTE — LOCAL REVIEW PACKAGE

65 unique genuine PDF files; 6 byte-identical duplicate uploads excluded. No demo files.

1. Extract this archive. Copy src/components/PastPapers.tsx, PastPapers.css and paperCatalog.ts into the project's src/components/.
2. Copy public/past-papers/ into the project's public/past-papers/ (local testing only).
3. Run npm run build && npm run dev.
4. Check the subject/year filters, Preview, Download and provincial versions.

IMPORTANT: This archive contains documents marked Confidential or with restricted reproduction notices. DO NOT COMMIT, PUSH OR DEPLOY the PDFs publicly without confirming authorization.
To avoid accidentally pushing PDFs, add /public/past-papers/ to .gitignore while reviewing locally. If any PDFs were previously tracked, .gitignore alone will not untrack them.
